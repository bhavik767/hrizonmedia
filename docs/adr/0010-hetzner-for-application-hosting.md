# Hetzner for application hosting

WeCloud will deploy its Next.js/Payload application and supporting services on Hetzner; Railway is no longer an active deployment target. This keeps the application on a conventional long-running self-managed platform while avoiding continued dependence on Railway-specific service, database, storage, or deployment configuration. A merge does not itself authorize or prove a Hetzner deployment: deployment automation, secrets, backups, monitoring, and rollback must be configured and verified separately.
